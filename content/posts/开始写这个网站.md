我一直不太信任「朋友圈」这种东西——内容会沉下去，顺序由算法决定，过两年可能连入口都找不到了。

所以我想要一个自己的地方：一个静态的、没有后端的网站，打开就能看到

- 我们**什么时候**发生了什么（时间表）
- 我们**还想**做什么（待办）
- 我们**长什么样**（照片）
- 以及偶尔写下来的废话（日记）

## 它是怎么搭的

用的是 [TnTeQAQ 的 blog-template](https://github.com/TnTeQAQ/blog-template)：
React + Vite，自带一个手写的 Markdown 渲染器，首屏是 Three.js 的粒子云，
整体黑白、克制，没有后端也没有数据库 —— 构建出来就是一堆静态文件，
放到 GitHub Pages 上就行。

我在这套模板上加了三样东西：

| 页面 | 数据在哪 | 怎么改 |
| --- | --- | --- |
| 时间表 | `src/data/timeline.ts` | 加一条记录，写日期和一句话 |
| 待办 | `src/data/todos.ts` | 加一行想做的事 |
| 照片 | `content/photos/` | 丢一张图片进去 |

写日记还是老样子：`npm run new -- "标题"`，生成 Markdown，写完 push。

## 之后

这个站大概不会天天更新。想起来了写两句，去了哪里就丢几张照片，
发生了一件值得记的事就往时间表上添一格。

慢一点没关系，重要的是它一直在。
