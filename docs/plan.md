## 1. 结论先给

需求书里的东西全都可做，但**不能一次做完**。本期（P1）只做两件，其余排期：

| 阶段 | 内容 | 价值 | 预估 |
| --- | --- | --- | --- |
| **P1（本期）** | 时间表「长河」：可缩放时间轴 L0/L1/L2；照片页编辑式版面 | 直接解决「拉到底没美感」+「流水账」 | 1.5 人日 |
| P2 | 首页开场字幕、待办手写划线、关于页的信 | 情绪铺垫 | 1.5 人日 |
| P3 | 相册对开翻页（拖拽/点击翻页） | 长期体验 | 2 人日 |
| P4 | 中文字体（得意黑 / 思源宋体子集化） | 质感跃升，但有体积与 FOUT 风险 | 1 人日 |

**理由**：时间轴是用户点名两次的痛点，且是「一屏一世界」的结构性改动，做完立刻能感知；照片页版面改动成本低、收益可见。首页字幕依赖后面的章节骨架，放 P2 更稳。

## 2. 技术决策（代替提问，直接拍）

| 议题 | 决策 | 理由 |
| --- | --- | --- |
| GSAP 要不要上 | **不上（P1/P2）** | 现有 anime.js 已覆盖 fade/slide/spring；GSAP 的 SplitText/ScrollTrigger 只有在做「滚动叙事」时才值。P3 若做翻页再评估 |
| 缩放怎么做 | **自研**：pointer events + 用 JS 计算每个节点的屏幕坐标 | 我们要的是**语义缩放**（文字不跟着放大），CSS `scale()` 会把字放大变形；d3-zoom 30KB 只为 pan/zoom，且同样要自己处理语义层级 |
| 滚轮语义 | 普通滚轮 = **横向平移**；`Ctrl/⌘ + 滚轮` 与双指捏合 = 缩放 | 地图式「滚轮即缩放」容易让用户以为页面坏了；横向平移符合「一条河」的隐喻 |
| 页面纵向滚动 | 时间表页**锁住**（整页一屏），靠 Esc / 「全部」按钮回全景 | 不锁会出现「页面滚动 + 内部平移」双滚动，手感一定塌 |
| 重要节点数据 | **复用现有 `highlight` 字段**作为 major | 零迁移、零编辑页改动；现有正好 6 个（9 月 3、10 月 3），符合「每篇最多 3 个」 |
| 篇章数据 | **按月派生**，标签写在 `src/data/chapters.ts` | 不新增字段，用户不用在编辑页选篇章 |
| 同一天多条 | 聚合成一个节点 + 角标计数，详情抽屉里列出当天全部 | 避免节点重叠；11-05 有三条，聚合后更好读 |
| 移动端降级 | 容器 `touch-action: none`，双指缩放 + 单指拖拽；缩放范围收窄到 [1, 4] | 避免与浏览器边缘返回手势打架 |
| 性能 | 24 个节点直接渲染，不做虚拟化；预留 >200 条再做可见区裁剪 | 当前规模虚拟化是过度设计 |

## 3. P1 交付物

### 3.1 时间表「长河」（重写 `src/pages/TimelineView.tsx`）

- 世界坐标：日期线性映射到 0..span，`span = 容器宽 - 左右留白`；屏幕 x = `pan + worldX * zoom`
- 视图状态：`{ zoom, pan }`，`zoom ∈ [1, 7]`，pan 的 clamp 保证内容不出界
- 分级：
  - `zoom < 2.2` → L0：只显示 major 标签、篇章带、月刻度
  - `zoom ≥ 2.2` → L1：所有节点标签出现
  - 点击节点 → L2：底部抽屉（桌面右侧抽屉）显示正文 + 配图，可上/下一条
- 时钟：月份刻度 + 年份；「现在」呼吸点固定在数据最右端
- 控件：`−` `+` `全部`，右上角显示当前视野（`2026 · 10月`），底部迷你进度条
- 键盘：`←/→` 节点间跳转，`+/-` 缩放，`0/Esc` 回全景
- 「待构建」条目继续合并显示（沿用现有 `mergeTimeline`）

### 3.2 照片页编辑式版面（改 `src/pages/GalleryView.tsx` + CSS）

- 每 7 张出现一个跨两列的「主图」，其余按 1:1 / 4:3 / 3:4 循环，形成大小穿插
- 进入视口：向上轻推 20px + 淡入 500ms，逐张 40ms 错开
- hover：`filter: grayscale(1)` → `grayscale(0)`，400ms
- 灯箱、上传按钮、待构建标记全部保留

`docs/design-brief.md`、`docs/plan.md` 随代码一起入库。

## 4. 风险与对策

| 风险 | 概率 | 对策 |
| --- | --- | --- |
| 缩放后标签重叠、闪烁 | 高 | 标签只在 major 或 `zoom≥2.2` 时渲染；同一像素区间做简单避让（间距 < 26px 时只留 major） |
| 触屏手势与浏览器冲突 | 中 | 容器 `touch-action: none`；提供「全部」按钮兜底；缩放上限放宽到 4 倍够用 |
| 小屏拥挤 | 中 | <560px 时隐藏标签（只留点），点击后看抽屉；篇章带文字缩短 |
| 深色模式对比不足 | 低 | 轴线用 `--border-soft`，节点用 `--fg`，沿用现有变量 |
| reduced-motion | 低 | 缩放/平移仍可用（那是操作），只关掉呼吸与淡入 |
| 与现有 snap 滚动打架 | 低 | 本页不走 `useSnapScroll`，独立布局 |
| 数据变多后性能 | 低 | 24 → 200 条仍可直渲；超过再做裁剪，已在代码里留注释 |
